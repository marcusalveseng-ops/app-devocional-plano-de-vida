# Conteúdo editorial

Pacote atual: `0.1-draft`, em `Sources/DevotionalCore/Editorial.swift`.

| Conteúdo | Origem | Condição atual |
|---|---|---|
| Exame geral, particular e breve | Redação inicial produzida para este projeto | Exige aprovação do responsável pelo produto e revisão de fidelidade católica antes de distribuição externa |
| Oferecimento do dia | Redação inicial produzida para este projeto | Mesma revisão pendente |
| Ave-Maria | Formulação tradicional em português | Conferir redação adotada e condições de distribuição antes do lançamento |
| Evangelho | Nenhuma fonte incorporada | Autorização e edição pendentes |
| Livros | Apenas título livre informado pela pessoa | Nenhum livro ou trecho de editora incorporado |

Os modelos de exame são copiados para cada atividade com identificadores próprios. Editar uma cópia não altera o modelo nem outro bloco. Cada pergunta é separada das notas pessoais.

## Antes do piloto externo

Registrar nome e data de aprovação, redação final, origem e condições de uso de cada texto. Incrementar a versão do pacote editorial quando os modelos mudarem. Uma atualização dos modelos não deve sobrescrever roteiros já editados pelas pessoas.

A denominação pública, identidade visual definitiva, preço e condições comerciais ainda dependem de decisão de produto. O ícone incluído é um desenho inicial feito para este projeto, sem imagem de terceiros.
