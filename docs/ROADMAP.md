# Roadmap

## 1. Definição

- [ ] Definir público, problema e resultado esperado.
- [ ] Delimitar o escopo da primeira versão e os itens fora de escopo.
- [ ] Definir conteúdo, fontes e permissões de uso aplicáveis.
- [ ] Definir critérios de sucesso e necessidades de acessibilidade.

## 2. Preparação técnica

- [ ] Escolher plataforma, tecnologia e armazenamento.
- [ ] Registrar decisões e requisitos de privacidade.
- [ ] Documentar instalação, configuração e execução local.

## 3. Primeira versão

- [ ] Criar issues com entregas pequenas e critérios de aceite.
- [ ] Implementar as funcionalidades aprovadas.
- [ ] Validar os fluxos com usuários e corrigir os problemas encontrados.

## 4. Publicação

- [ ] Definir hospedagem e processo de entrega.
- [ ] Registrar validações, versão, endereço publicado e procedimento de reversão.
- [ ] Publicar release com notas de versão.

## 5. Manutenção

- [ ] Acompanhar feedback e falhas.
- [ ] Priorizar melhorias e atualizar documentação.
- [ ] Revisar dependências e rotinas de recuperação de dados, quando aplicáveis.
